## Descripción del Proyecto
Este proyecto consiste en una página web estructurada en HTML creada para aprender y aplicar el flujo de trabajo estándar con Git y GitHub:
- Inicialización y configuración de repositorio local y remoto.
- Exclusión de directorios de entorno (`.vscode/`) a través del fichero `.gitignore`.
- Flujo de trabajo por ramas (`feature/*`) para el desarrollo de funcionalidades independientes.
- Commits descriptivos y sincronización de cambios.
- Integración de código en la rama principal `main` mediante Pull Requests (PR).
